# Conversion Courier

Conversion Courier is a retro-inspired arcade game built with Phaser 3 and TypeScript. It reimagines the classic Paperboy mechanics as a solopreneur’s journey through the four stages of a conversion funnel: awareness, consideration, decision, and advocacy. Each level challenges players to deliver digital assets, dodge distractions, and build their online presence. High-performing players unlock a Battleship-style bonus mini-game to earn Hustle Credits for temporary buffs, while optional a‑la‑carte upgrades offer permanent buffs between stages.

## Features

- 4 distinct stages representing conversion funnel stages.
- Multiple selectable solopreneur characters, each with unique buffs and debuffs.
- Dynamic obstacles and power-ups along the route.
- Bonus mini-game unlocked at ≥85% completion rate.
- Hustle Shop for temporary buffs.
- Optional upsell CTA screens for permanent upgrades.
- Clean, modular codebase structured around Phaser scenes and configuration files.

## Getting Started

This project uses [Phaser 3](https://phaser.io) with TypeScript and Vite.

1. Clone the repository and install dependencies:

```
npm install
```

2. Start a development server:

```
npm run dev
```

3. Open `http://localhost:3000` in your browser to play.

## Project Structure

- `src/` — TypeScript source files for game logic and scenes.
- `config/` — Game configuration for characters, stages, and text.
- `docs/` — Planning documents and design notes.
